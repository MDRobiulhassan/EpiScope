# AI Usage Disclosure

## Project
EpiScope: Big Data Analytics for Disease Surveillance

## AI Tools Used
ChatGPT was used as an AI-assisted development and documentation tool.

## Areas of Assistance
- Troubleshooting Python, PySpark, and pipeline execution issues.
- Reviewing Spark configuration options and planning performance experiments.
- Interpreting runtime measurements, scaling results, and evaluation metrics.
- Assisting with code review, validation steps, and technical documentation.
- Helping organize the project report and explain system limitations.

## Human Responsibility and Verification
The project author ran the code and experiments in the development environment,
reviewed the outputs, and is responsible for the submitted implementation,
analysis, and conclusions. Benchmark figures reported in the project should be
based on recorded experiment results rather than AI-generated estimates.

## Data and Evaluation Limitations
Encounter records and outbreak labels in this project are synthetic. The
detection and forecasting components are prototypes evaluated on synthetic
data; their measured performance does not establish effectiveness in real-world
public-health surveillance. Weather-related fields should not be represented
as observations from real weather stations unless independently verified.

## Integrity Statement
AI assistance was used to support development and explanation. Any AI-assisted
code or text included in the submission should be reviewed by the author for
correctness, understanding, and compliance with the course's AI-use policy.
